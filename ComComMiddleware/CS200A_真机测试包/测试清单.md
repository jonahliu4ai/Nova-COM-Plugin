## 1. 接线与串口

ComComMiddleware 是**双串口网关**：

```
PicoView/Nova 等上位软件 ──COM A── [ComComMiddleware] ──COM B── CS200A (USB-485)
```

- **COM A（对上）**：给上位软件连接的端口。用 com0com 虚拟端口对时（如 COM7↔COM8），
  这里填其中一端（如 COM7），PicoView 打开另一端（COM8）。
  测试机已装 com0com；**建/删端口对用命令行**（管理员权限）：

  ```
  :: 建 COM7<->COM8 端口对（重复执行会提示已存在，无害）
  "C:\Program Files (x86)\com0com\setupc.exe" install 0 PortName=COM7 PortName=COM8

  :: 查看已有端口对
  "C:\Program Files (x86)\com0com\setupc.exe" list

  :: 需要删掉重建时（0 是端口对编号，以 list 输出为准）
  "C:\Program Files (x86)\com0com\setupc.exe" remove 0
  ```
- **COM B（对下）**：真实设备端口，USB-485 转换器在设备管理器中的 COM 号：COM____

检查项：

- [ ] com0com 端口对已建好：`setupc list` 能看到 COM7<->COM8（编号和端口号以实际为准）
- [ ] PicoView 打开的端口与网关 COM A 是同一对的**两端**（接反了会两边都无声无息）
- [ ] RS-485：A→A、B→B（若通信不通且怀疑线序，断电后互换 A/B 再试）
- [ ] 转换器参数：19200、8、N、1（与设备出厂一致）

## 2. 启动软件

1. 运行 `ComComMiddleware.exe`
2. **COM A** 填 com0com 一端（对上），**COM B** 填 USB-485 的 COM 口（对下），打开
3. 点击 **Load** 加载本文件夹的 `七星华创_CS200A.json`
4. 命令输入格式。**推荐用纯 ASCII 别名 `CS200A`**，彻底避开中文编码问题：

```
DEVICE=CS200A;CMD=read_flow
DEVICE=CS200A;ADDR=66;CMD=read_flow      ← 地址不是 66 时这样覆盖
@CS200A read_flow                        ← @ 写法同样支持别名
@CS200A ADDR=66 read_flow                ← @ 写法加地址（放命令后也行，A=66 可缩写）
```

中文名 `DEVICE=七星华创_CS200A;...` 也可以，但要求发送端按 **UTF-8** 编码发送
（网关 COM A 已固定为 UTF-8；PicoView 若按 GBK 发送会收到 `ERR:ProfileNotFound:????`，
这是正常现象，换别名即可）。

> 若仍收到 `ERR:NoDevice`：说明命令行里的 `=`/`;` 被输入法转成了全角（＝；），
> 或 DEVICE 段缺失。网关界面日志区会打出原始字节（`ERR:NoDevice, raw=...`），
> 把该行记下来反馈。

## 3. 通信与读数验证

| # | 操作 / 命令 | 通过标准 | 结果 |
|---|---|---|---|
| 1 | `read_device_info` | 返回设备型号/序列号字符串（非 ERR、非超时） | ☐ |
| 2 | 关阀状态下 `read_flow` | 接近 0，允许小幅负值（手册 §3.3 负流量为正常） | ☐ |

## 排查表

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 全部命令 `OK|NoRsp` 或超时 | ① COM B 选错 ② A/B 接反 ③ 地址不是 66 ④ 485 转换器未供电/未装驱动 | 逐项确认；地址问题用 `ADDR=` 覆盖试几个常见值（66、1、32）；仍不行用七星配置工具读地址 |
| `ERR:NoDevice` | 命令行 `=`/`;` 被转成全角，或 DEVICE 段缺失 | 检查输入法；看网关日志区 `raw=` 行的原始字节 |
| `ERR:ProfileNotFound:????` | 发送端用 GBK 发中文设备名（网关 COM A 是 UTF-8） | 改用别名：`DEVICE=CS200A;CMD=...` |
| 返回 `ERR:NAK` | 地址错误（设备收到了但不是你） | 换地址重试 |
| 返回 `ERR:BadChecksum` | 线路上有干扰或转换器问题 | 检查屏蔽/接地；换转换器试 |
| 流量值差一个固定倍数 | `full_scale` 与设备实际满量程不一致 | 改 JSON 中 `full_scale` 为铭牌值，重新 Load |
| 流量为 0 但气路确定有流量 | 阀门处于关闭控制模式 | `set_control_mode 2`（流量控制模式）后再测 |
| 偶发 `NoRsp`（<1/20 次） | 手册 §8 缓冲残留，引擎已做鲁棒处理 | 记录频率，连续出现再反馈 |
| `read_temperature` 数值离谱 | 温度换算 scale/offset 与固件版本不符 | 记录原始返回值反馈（JSON 现为 ×0.0806 −50） |
